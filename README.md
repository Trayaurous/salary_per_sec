# 秒薪计算器

纯前端的秒薪计数器，按东八区时间计算每日收入，也可以手动从零计时。

## 使用

点击右上角设置，填写月薪与当天上下班时间；午休可留空。双休为周六、周日休息；单休为周日休息。法定节假日和调休不计入。

- **今日**：按当前时间显示今日已赚金额；午休时冻结数字，下班和休息日金额面板留空。
- **计时**：从零累计金额，小屏幕显示经过时间。可开始、暂停、继续或归零，任何时段均可使用。
- 切回今日模式会暂停手动计时；刷新后保存结果并暂停。
- 设置与计时结果存储在本浏览器的 localStorage 中，换设备、换浏览器或更换访问域名不会同步。浏览器存储不可用时，仅当前页面可使用设置。
- 时间来源为设备时钟，日期和作息始终使用 UTC+8。首版支持当天班次与一段午休。

## 检查

```sh
npm test
npm run check
```

测试覆盖东八区、工作日计数、午休边界、千元显示门槛、跨月秒薪、暂停恢复与刷新后的状态。

## 文件

- `index.html`、`styles.css`：界面与拟物化外观。
- `src/calculations.js`：东八区、工作日与薪资计算。
- `src/timer.js`：手动计时与恢复。
- `src/displays.js`：翻页金额与七段管显示。
- `src/app.js`：交互、配置和本地保存。
- `scripts/serve.mjs`：本地静态预览服务器。
- `DEVELOPMENT.md`：需求与验收规则。
